# Wheelchair 1.3.178

Native x86-64 AOT compiler. Build with `sh build.sh` using GNU binutils. Seven canonical tools are provided in `bin/`; `wheelchairc` is the production launcher. Production compilation and generated programs require no Python, GCC, LLVM or libc.

This release shares checked scalar facts at their first unconditional demand, unifies immutable scalar bit carriers, and removes the native division/remainder stack bridge. Iteration work now prices the actual steady-state loop span separately from initialization and publication.

Strict operand order, rounding, simultaneous updates, lazy errors and integer overflow contracts remain unchanged. Existing Rank-N / Axis / Operator / Region / Effect / Capability / Physical Reality / Physical DAG remain the common authorities. No workload selector, compatibility recurrence backend, user scheduling annotation or additional runtime scheduler is introduced.

See RELEASE_NOTES_1_3_178.md for implementation scope and limits. The accompanying measured report contains current-machine comparisons, correctness checks and archive verification. No hardware peak-throughput percentage is claimed.
