# Contributing

Wheelchair does not accept external code contributions.

The following are not accepted:

- pull requests
- patches
- feature requests
- optimization suggestions
- architectural suggestions
- implementation advice

This repository accepts only reproducible reports about:

- performance problems
- correctness problems

Reports must be submitted through the provided issue form.

A valid report should include:

- a minimal reproducible Wheelchair example
- the mathematical or computational problem being solved
- exact build and execution information
- workload definition
- observed result
- expected result
- reference code only in C, Fortran, Julia, Assembly, or AVX-family intrinsics when comparison is needed

Reports describe observations, not solutions.

The project direction, implementation, and all design decisions are maintained exclusively by the author.
