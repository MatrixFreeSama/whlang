# Wheelchair 1.2.13 Pure-Assembly Release Proof

The production closure contains no Python source and requires no Python interpreter.

1.2.13 adds execution-representation compression entirely inside the handwritten assembly derived frontend. The release gate is also rerun with a PATH that contains no `python` or `python3` executable.

The dense optimization is guarded by structural recognition of canonical static power-of-two Rank-N suffix coordinates. Irregular rank-1 sparse code cannot enter the path, and the authority q1/q2/q4 sparse executables are required to retain their 1.2.12 SHA-256 values exactly.

Release authority is `test_release_native_1213.sh` plus the no-Python PATH rerun.
