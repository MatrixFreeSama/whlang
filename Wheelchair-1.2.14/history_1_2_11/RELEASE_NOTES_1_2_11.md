# Wheelchair 1.2.11 Release Notes

1.2.11 is a corrective native-physicalization release.

The 1.2.10 final launcher could select `base` for structurally high-pressure tensor programs whose canonical resource profile required `wide`. This did not change numerical semantics, but it could erase a mature physical performance peak. The coupled fluid-solid benchmark exposed the defect.

1.2.11 fixes the issue without reintroducing Python or runtime policy. `wheelchairc` / `whexc` now link the handwritten surface lowerer, canonicalize human source in-process for classification, count distinct canonical structural load objects, and make one AOT physical capability choice before compilation.

Resource classes remain generic:

- base persistent register domain: pressure <= 10;
- wide expanded persistent register domain: pressure 11..14;
- base vector recompute: pressure > 14;
- derived Rank-N Cartesian physicalizer: explicit proved Rank-N metadata.

No workload names, benchmark names, file paths, timing measurements, runtime profitability decisions, or failure-driven retries participate in the choice.

The FSI regression now requires automatic `whexc` output to be byte-identical to explicit `topologyc-wide` output for Q1/Q2/Q4.
