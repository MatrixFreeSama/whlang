# Wheelchair 1.2.14 Pure-Assembly Release Proof

The production closure contains no Python source and requires no Python interpreter.

1.2.14 implements the caretaker passes entirely inside the frozen handwritten x86-64 derived frontend. Production build authority remains shell plus native binutils and native Wheelchair executables.

The release requires both normal-PATH and no-Python-PATH runs of `test_release_native_1214.sh`.

High-entropy sparse protection is machine-image authority, not a timing heuristic: q1/q2/q4 irregular sparse executables must retain the exact SHA-256 values inherited from 1.2.12/1.2.13.

Dense transformations are admitted from Rank-N structural proofs and explicit numerical contracts. Workload names, wall-clock timings, runtime profitability sampling, JIT profiling, and global fast-math are absent.
